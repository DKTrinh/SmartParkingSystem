Hướng dẫn cài đặt 
- Bước 1: Clone dự án từ git hub về: Mở terminal trên Vscode và chạy lệnh sau: git clone https://github.com/Phuoc205/Smart-Parking-System.git 
- Bước 2: Mở dự án FE-SPS ra 
- Bước 3: Cài đặt môi trường npm: Chạy lần lượt các lệnh này:
+ npm install
+ npm install --save-dev babel-loader @babel/core @babel/preset-env @babel/preset-react
+ npm install react@18 react-dom@18 Như vậy là đã cài đặt xong rồi, bây h muốn chạy dự án chỉ cần chạy lệnh này trên Terminal: npm start Nếu chạy ko dc thì hỏi Phước hoặc chatgpt nha
